# 点位数据、底图与许可

本项目保留完整候选点和公开观测点。不同来源的数据分别说明，不因放在同一仓库中就具有相同的许可或可信度。

### 候选点来源

历史候选点来自 [A2Helper](https://a2helper.app/) 0.1.25 的已分发资源。对应分发项目为 [oPodera/a2helper-download](https://github.com/oPodera/a2helper-download)。具体来源文件、版本、计数及哈希见 [data/provenance.json](../data/provenance.json) 与候选文件内的 `source` 字段。

`source_count` 与 `unique_count` 使用不同口径：前者保留来源点位总量，后者描述去重后的点位。不能把合并后的点数称为来源全部记录，也不能把来源总量称为当前红背包数量。

候选点缺少逐点的实时刷新、开启状态和红色类型确认。它们用于历史位置参考；实际收到的红色背包观测应单独显示，不能用候选点制造“刚发现”的通知。

**许可条件尚未完成：** 目前没有确认 A2Helper 对该候选数据授予了可适用的再分发许可，也没有将其重新许可为 MIT 的依据。完整保留文件和出处有助于审查，但不构成许可。包含这些点位的公开发布与下游再分发，仍需核实来源许可证或取得相应授权。不得以本仓库的 MIT 文件替代该条件。

本项目与 A2Helper、游戏开发商及运营方没有在此声明任何合作或认可关系。

### 公开观测数据

`data/observations.json` 是明确选定的公开快照，与用户日常使用时的个人存档分开。公开记录反映接收到坐标与状态的历史事实，不证明目标现在仍然存在，也不自动确定背包由谁开启。

更新公开数据时，应保留坐标、地图、记录状态及必要的时间依据，同时检查是否泄露个人身份或运行环境。不要复制原始抓包、连接 IP、账户或角色标识、本机绝对路径、控制令牌或完整运行日志。仅删除姓名并不等于原始网络数据已经适合公开。

点位校正应记录来源和原因。不要静默改动时间来伪造刷新周期，也不要把颜色未知的候选点改成已确认的红背包观测。

### 导出自己的观测副本

[scripts/export_observations.py](../scripts/export_observations.py) 只读取明确指定的 schema 1 历史 JSON，不自动寻找个人存档。先将要公开的数据导出到审阅文件，例如：

```powershell
.venv/Scripts/python.exe scripts/export_observations.py --input private/history.json --output build/observations-review.json
```

将 `private/history.json` 替换为自己选择的输入文件。脚本保留全部记录，包括同坐标或旧周期的记录；不按坐标去重。输出仅保留地图、X/Y/Z、状态和历史时间字段，并生成不依赖私有元数据的稳定 ID，来源标记为 `local-observation`。缺失时间保留为 `null`，`record_count` 等于输出记录数。

**指定的输出文件若已存在会被替换**，所以审阅阶段使用单独路径，不直接指向正式的 `data/observations.json`。脚本先验证全部输入，再原子写入；拒绝覆盖输入文件，坏记录会报出序号和字段。导出不启动接收、不请求本机服务、不上传数据。检查审阅文件及其来源授权后，再决定是否更新正式公开快照。

## 底图导入

公开源码与发布包不包含第三方地图图片或来自其资源包的校准版 `maps.json`。首次打开使用坐标网格，候选点与观测点仍可以按坐标显示。

有权使用相应素材的用户，可在桌面管理窗口点击“导入地图资源”，选择本地资源目录。导入后按界面提示重新打开地图窗口。支持以下布局：

```text
资源目录/
├── maps.json
└── maps/
    ├── 1110.webp
    └── 1110/
        ├── 0_0.webp
        └── …
```

也支持旧资源包中的 `static/maps/` 图片目录。`maps.json` 提供每张图的 ID、世界坐标范围和可选瓦片配置。图片与坐标配置必须配套，否则标记会偏移。程序内部的导入入口是 `import_assets(source_dir, data_dir)`，导入目标为 `data_dir/assets/`。

导入只处理用户选择的本地文件，不自动下载素材、登录第三方服务或取得额外许可。不要把本机导入的资源再次装进公开仓库或发布包，除非已经核实其再分发权利。

坐标约 100 个世界单位对应 1 米。平面距离使用 X/Y，Z 表示高度；地图上的直线距离不是可通行路线，也不包含地形障碍。
